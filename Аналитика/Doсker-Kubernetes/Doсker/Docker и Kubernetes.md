# 📌 Введение в Docker и Kubernetes — теоретическая база

## 🐳 Что такое Docker

**Docker** — это платформа для создания, доставки и запуска приложений в виде изолированных контейнеров.

Контейнер — это лёгкая, переносимая среда, содержащая всё необходимое для работы приложения: код, зависимости, библиотеки, системные инструменты.

---

### 🔧 Ключевые понятия Docker

- **Docker Image** — неизменяемый шаблон контейнера
    
- **Docker Container** — запущенный экземпляр образа
    
- **Dockerfile** — сценарий для сборки образа
    
- **Docker Hub** — публичный реестр образов
    
- **docker-compose** — инструмент для описания и запуска многоконтейнерных приложений
    

---

### ✅ Преимущества Docker

- Изоляция и предсказуемость окружения
    
- Упрощение CI/CD
    
- Переносимость между разработкой, тестом и продом
    
- Быстрый запуск и масштабирование
    

---

## ☸️ Что такое Kubernetes

**Kubernetes (K8s)** — это система оркестрации контейнеров, предназначенная для автоматического развертывания, масштабирования и управления контейнеризированными приложениями.

Он управляет контейнерами в кластере из множества серверов (нод).

---

### 🔧 Ключевые компоненты Kubernetes

- **Pod** — минимальная единица развертывания (один или несколько контейнеров)
    
- **Node** — рабочий сервер в кластере
    
- **Cluster** — совокупность нод
    
- **Deployment** — описание стратегии выкатывания и количества реплик
    
- **Service** — стабильная точка доступа к Pod’ам
    
- **Ingress** — маршрутизация внешнего трафика внутрь кластера
    
- **ConfigMap/Secret** — хранение конфигураций и секретов
    

---

### ✅ Преимущества Kubernetes

- Автоматическое масштабирование и восстановление
    
- Rollout и rollback без простоев
    
- Балансировка нагрузки между контейнерами
    
- Декларативные манифесты (YAML)
    
- Интеграция с облаками (GCP, AWS, Azure)
    

---

## 🔁 Docker vs Kubernetes

|Параметр|Docker (Engine)|Kubernetes|
|---|---|---|
|Назначение|Запуск отдельных контейнеров|Управление множеством контейнеров|
|Масштабируемость|Ручная|Автоматическая|
|Устойчивость|Зависит от Docker Host|Встроенная самовосстановляемость|
|Уровень|Операционная среда|Система управления кластерами|

---

## 🧪 Использование вместе

- Docker используется для создания контейнеров
    
- Kubernetes — для управления их работой в продакшне
    
- Kubernetes может использовать Docker, containerd или другие движки
    

---

### 📄 Примеры

#### Пример `Dockerfile`

```Dockerfile
# Используем официальный образ Node.js
FROM node:18

# Устанавливаем рабочую директорию
WORKDIR /app

# Копируем package.json и устанавливаем зависимости
COPY package*.json ./
RUN npm install

# Копируем исходный код
COPY . .

# Запускаем приложение
CMD ["npm", "start"]
```

#### Пример `docker-compose.yml`

```yaml
version: '3.8'
services:
  web:
    build: .
    ports:
      - "3000:3000"
    volumes:
      - .:/app
    environment:
      - NODE_ENV=development
```

#### Пример манифеста Deployment для Kubernetes (`deployment.yaml`)

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 2
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-app
          image: my-app-image:latest
          ports:
            - containerPort: 3000
```

#### Пример манифеста Service для Kubernetes (`service.yaml`)

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
    - protocol: TCP
      port: 80
      targetPort: 3000
  type: LoadBalancer
```
