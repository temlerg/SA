# Требование
- Существуют сотрудники (ФИО, пол, дата рождения, дата приема на работу).
- Сотрудники работают в отделах. Сотрудник может работать сразу в нескольких отделах одновременно.
- У каждого отдела есть менеджер. Менеджер назначается на должность и может быть с нее снят. Требуется хранить период работы менеджером.
- Сотрудник назначается на должность: 
	- Несколько сотрудников могут быть назначены на одну должность.
	- Сотрудник может переходить с одной должности на другую. Требуется хранить в БД дату начала работы на этой должности и дату окончания.
	- Должность != Менеджер, это разные сущности.
