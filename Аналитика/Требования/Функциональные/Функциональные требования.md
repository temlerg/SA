# 📌 Что такое функциональные требования

**Функциональные требования** — это описание того, _что должна делать система_, чтобы удовлетворить потребности пользователей и реализовать бизнес-логику. Они отражают поведение системы при взаимодействии с пользователем, другими системами или событиями.

---

## 💡 Примеры функциональных требований

- Пользователь должен иметь возможность зарегистрироваться через email и пароль
    
- Система должна отправлять уведомление на почту при изменении статуса заказа
    
- API должен возвращать список заказов, отфильтрованных по дате
    
- При вводе неверного пароля система должна вывести сообщение об ошибке
    

---

## 🧱 Структура функционального требования

1. **ID** — уникальный идентификатор (например, FR-001)
    
2. **Название** — краткое описание функции
    
3. **Описание** — полное описание поведения системы
    
4. **Условия выполнения** — что должно быть выполнено для активации функции
    
5. **Результат** — что происходит после выполнения действия

## ✅ Хорошее функциональное требование:

- Однозначно трактуемо
    
- Проверяемо (можно протестировать)
    
- Реализуемо
    
- Не описывает _как_ реализовать — только _что_ должно быть
