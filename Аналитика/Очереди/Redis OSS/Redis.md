# 🧠 Redis — краткое введение и архитектура

**Redis (Remote Dictionary Server)** — это открытая, высокопроизводительная система хранения данных в памяти с поддержкой структуры ключ-значение. Redis используется как кэш, брокер сообщений, счётчик, pub/sub-канал и хранилище состояний.

---

## 🚀 Основные характеристики

- Хранение данных в оперативной памяти с возможностью асинхронной записи на диск
    
- Поддержка различных структур данных: строки, списки, множества, хэши, упорядоченные множества, битовые карты и др.
    
- Очень высокая скорость чтения и записи
    
- Поддержка кластеризации и репликации
    

---

## 🧱 Структура и компоненты

- **Key** — уникальный идентификатор записи
    
- **Value** — может быть строкой, списком, хэшом и т.д.
    
- **Client** — обращается к Redis-серверу через TCP или Unix-сокет
    
- **Redis Server** — отвечает за хранение и обслуживание данных
    
- **Persistence** — два режима сохранения: RDB (снимки) и AOF (журнал команд)
    

---

## 🛠 Типовые случаи применения

- Кэширование часто запрашиваемых данных (например, HTML, API-ответов)
    
- Хранение временных сессий пользователей
    
- Счётчики и рейтинги
    
- Очереди заданий (например, через списки)
    
- Pub/Sub (механизм публикации/подписки)
    
- Хранение флагов и токенов
    

---

## 📦 Структуры данных в Redis

|Тип|Описание|Пример применения|
|---|---|---|
|String|Простое значение|Кэш HTML, токен, число|
|List|Последовательность элементов|Очередь задач|
|Set|Уникальные значения без порядка|Подписчики, уникальные ID|
|Hash|Ассоциативный массив (ключ: значение)|Профили пользователей|
|Sorted Set|Множество с приоритетами (score)|Рейтинги, лидерборды|
|Bitmap|Хранение битов|Отслеживание активности|

---

## 🔐 Безопасность и управление

- Аутентификация через пароль (AUTH)
    
- Контроль доступа к командам
    
- Поддержка TLS/SSL
    
- Мониторинг через INFO, MONITOR, Redis CLI
    

---

## 📊 Кластеризация и масштабирование

- **Master/Replica** — репликация данных
    
- **Sentinel** — автоматическое восстановление при сбое мастера
    
- **Cluster Mode** — распределение ключей по нодам
    

---

## 🗺 Архитектура Redis (текстово)

```
[Client] --> [Redis Server] --> [RAM + (AOF|RDB)]
                             ↘ optional replica nodes
```
